# Mindflow

ブラウザで使える個人用マインドマップアプリです。

## 使い方

`index.html` をブラウザで開いて使います。

マップは自動保存されません。変更後は **名前を付けて保存** でJSONファイルとして保存してください。

## 対応ブラウザ

- Chrome（デスクトップ版）
- Microsoft Edge（デスクトップ版）

Chrome / Edgeでは、**名前を付けて保存** の後に **上書き保存** を使えます。ファイルへの書き込み権限はページを閉じると失われるため、開き直した後はもう一度「名前を付けて保存」を行ってください。

その他のブラウザでは、JSONのダウンロード保存を利用できます。上書き保存は利用できません。
